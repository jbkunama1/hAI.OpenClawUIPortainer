hAI.OpenClawUIPortainer

Open WebUI + OpenAI-kompatibles Agent-Gateway mit MCP-Tools und Telegram-Kanal. Self-hosted als Portainer-Stack.

GitHub-Repository

Architektur

👤 Du→ 💬 Open WebUI→ 🦞 OpenClaw Gateway→ 🧠 LLM (BYOK)
📱 Telegram→ 🦞 OpenClaw Gateway↔ 🧰 MCP-Server

Features

💬 Open WebUI

Chat-Oberfläche im Browser auf Port 8666.

🔑 BYOK

OpenAI, OpenRouter, Ollama oder jeder OpenAI-kompatible Anbieter.

🧰 MCP-Client

Streamable HTTP mit SSE-Fallback, stdio, Auto-Reconnect.

🤖 Agent-Schleife

Tool-Calling mit Allowlist, Ergebnis-Limit und Streaming.

📱 Telegram

Ein- und Ausgabekanal mit bunten Inline-Buttons.

✅ Freigabe

Schreibende Tools laufen erst nach Bestätigung per Button.

Telegram-Buttons

📊 Status 🛠 Tools 🆕 Neuer Chat ✅ Ausführen ❌ Abbrechen

Portainer-Deployment

  1. Externes Netzwerk anlegen: docker network create highfishNetwork
  2. In Portainer Stacks → Add stack → Repository wählen.
  3. Repository-URL https://github.com/jbkunama1/hAI.OpenClawUIPortainer.git, Branch main.
  4. Environment-Variablen setzen: GATEWAY_TOKEN, LLM_BASE_URL, LLM_API_KEY, WEBUI_SECRET_KEY.
  5. Stack deployen und http://SERVER-IP:8666 öffnen.

Sicherheit

  • Keine Keys, Tokens oder MCP-URLs im Repository – nur in der Portainer-Environment.
  • TELEGRAM_ALLOWED_USERS setzen, sonst bleibt der Bot im Einrichtungsmodus.
  • Backend-Port 3000 nicht nach außen freigeben, für Internetzugriff HTTPS vorschalten.
